1. Description of Service

AttendMate is a local-first companion application designed to help students track class attendance, calculate bunk allowances, configure optional classroom geofences for attendance reminders, import and export historical attendance datasets, synchronize timetables with Google Calendar, and maintain optional secure backups via Google Drive.

2. Location Services & Geofencing

The App offers optional location-based features (such as geofence attendance verification and proximity reminders):

  • User Authorization: Location features function solely when you voluntarily grant device location permissions.
  • Accuracy Disclaimer: Geofencing accuracy depends on your device hardware, GPS reception, network conditions, and operating system energy optimizations. We do not guarantee uninterrupted or error-free location detection.
  • Local Processing: All location data is processed strictly on your physical device and is never transmitted to external servers.
